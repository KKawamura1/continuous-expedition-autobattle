# 坑の前線（連続進軍オートバトル試作）

スマートフォンの縦画面で、自律して戦う調査隊を観察し、好きなときに一時停止して改造するゲームの試作です。購入した部品が戦場でどう噛み合い、前線をどこまで押し上げるかを試します。

## 起動

Node.js 20.19以降または22.12以降を用意します。

```sh
npm install
npm run dev
```

表示されたURLをブラウザで開きます。iPhoneで試す場合は、同じネットワーク上のPCで起動し、表示されたNetwork URLを開けます。`npm test`で戦闘と拠点のルールを、`npm run build`で配布用ビルドを確認できます。

## Cloudflare Workers

Cloudflare WorkersのGit連携でこのGitHubリポジトリを接続すると、Production branch（`main`）への更新で本番公開され、Preview buildsを有効にすると他のブランチやプルリクエストにプレビューURLが作られます。プレビューURLはプルリクエストにも投稿されます。

設定値は次の通りです。

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Preview command: `npx wrangler preview`
- Root directory: `/`

`wrangler.jsonc`ではViteの出力先`dist`をWorkers Static Assetsとして配信し、Workers Preview URLを有効にしています。`npm run build`はTypeScriptの型検査を通してからViteで公開ファイルを作ります。Cloudflareがビルドとデプロイを行うため、GitHub Actionsは使いません。

## 遊び方

1. 「進軍を再開」で自律戦闘を始めます。画面上から現れる敵を5人が自動で迎えます。
2. 距離、進軍速度、敵の滞留、撃破圧、被害、収入を観察します。
3. 「改造・一時停止」で時間を止めます。敵を倒して得た遠征資金を、戦い方を変える部品や性能の調整に使えます。
4. 再開して変化を観察します。300mごとの中継拠点では自動停止し、全額を再配分できます。
5. 危険域でも自動停止します。資金で改造して進むか、最後の拠点へ撤退できます。ページを閉じても、その地点から停止状態で再開できます。

再生速度は1×、2×、4×に切り替えられます。別のタブへ移ると戦闘は停止します。

## 今回の実装範囲

5人の調査隊、4種類の敵、13種類の改造、距離に応じた敵の流入と強化、前線の進軍・後退、拠点での保存と再配分を一つの画面に収めています。坑、記録、5人の人物は以前の案から着想を得た仮の表現です。具体的な物語や技能体系は、戦闘の手応えを見て育てる予定です。

敵と味方は位置を持ちます。射撃による引き寄せ、衝撃による押し出し、接触による損傷、周囲への薙ぎ払い、近くの敵へ跳ぶ鎖雷などは、この位置や重量を共有します。共通の戦場を介して、組み合わせが生まれます。

進軍速度は直近の撃破圧と被害から決まり、敵流入は処理負荷として働きます。数値と改造候補は検証用です。[試作の実装判断](docs/prototype-notes.md) に詳しく記しました。
