# 連続進軍オートバトル（仮）

スマートフォンの縦画面で、自律して戦うパーティを観察し、好きなときに一時停止して強化するゲームの構想です。購入した部品が戦場でどう噛み合い、前線をどこまで押し上げるかを試すことを中心に据えます。

## 遊びの流れ

1. パーティが連続して現れる敵と自動で戦い、前線が進む・膠着する・後退する。
2. 距離、進軍速度、敵の滞留や被害を見て、次に変えたいことを考える。
3. 任意に一時停止し、得た資金で戦闘の仕組みや性能を変える。
4. 再開して変化を観察する。拠点への到達を区切りとして、構成を見直して先へ進む。

距離・位置・速度・密度など、共通の戦場の性質から思いがけない連鎖が生まれることを目指します。敵との相性に応じて、同じビルドの使い方を工夫できるゲームにしたいです。
