# まだ、先へ。

超巨大な古代龍蛇と、その背中で勝手に過ごす少女が、乾いた荒野を進むスマホ縦画面の連続遠征オートバトル。

[巨大生物モチーフ企画](docs/giant-creature-concept-2026-10-02.md)と[身体変異システム案](docs/body-mutation-system-2026-10-02.md)をもとにした、Canvasのプレイ可能な試作です。

## 遊び方

STARTで遠征を始めます。龍蛇は自動で噛み、角を振って、上から来る甲虫・狼・猪を迎撃します。背景が下へ流れると前進、上へ戻ると後退です。敵が身体に溜まると押され、傷つきます。

下端のハンドル、下部の身体のタップ、または上スワイプで、身体を引き上げます。戦闘が止まり、画面外にあった胴体が現れます。5つの身体部位を触り、敵から得た成長資源で変異します。下スワイプかハンドルで身体を戻すと、遠征を再開します。キーボードではSpaceでも切り替えられます。

区間中の変異は取り消せません。購入済みの変異はすべて働きます。購入が増えると次の変異の必要資源も少し増えます。

300mごとの拠点でひと息つきます。遺骨の記憶を1つ獲得し、新しい変異を選んで解禁できます。再出発時には区間の身体・資源をリセットし、解禁した候補を含めて再構築します。身体が倒れた場合も直前の拠点から組み直せます。

進行は端末に自動保存します。再読込時やアプリを離れたときは戦闘を止め、次に触るまで敵が動かないようにしています。以前の5人パーティのセーブとは別の保存キーを使います。

## 画面の読み方

戦闘中は左上の◇が成長資源、右端の縦ルートが次の拠点までの区間進捗です。下端の細いラインで龍蛇HPを確認できます。傷ついた敵には短いHPバーが約2秒間出ます。猪には満タン時も薄いバーがあります。

角は見えている斜面に敵が当たると、接触面に沿って中央・口元へ受け流します。角は頭に固定され、首を支点に角・目・顎・頭部の鱗が一体で切り返します。その動きで当たった敵を弾きます。枝角は枝が増え、大顎は口の幅が広がります。描画と当たり判定は同じ形状を使います。

舌と触手は実際に伸びた先端の鉤が敵に引っ掛かってから縮みます。届かなかった敵には力が伝わりません。棘・鉤・弾性鱗は敵が触れる身体の縁にも生え、擦り傷・摩擦・反発が接触位置で発生します。反発時は鱗が凹んで戻り、敵が実際に跳ね返ります。接触に小さな砂埃を添え、身体の形・運動・敵の動きで因果を示します。

身体上の選択点から部位別の候補を開きます。段階別の2列カタログをスクロールし、候補を選ぶと数値と関係が展開されます。「前提」「次に開く」「排他」「相性」の変異名は、他部位の詳細にも移動できるリンクです。取得済みの変異は全体表示の「現在の身体」から再確認できます。新候補は`MUTATIONS`・`INFO`、新部位の選択点は`PARTS`の身体座標に追加します。物理的な変異は`body-physics.ts`で形状・接触・運動を定義し、その同じ形状を描画に使います。範囲内の敵への直接加速ではなく、器官が触れた位置から力を伝えます。

旧v2セーブは敵の最大HPを補完して読み込みます。旧セーブで既に取得した排他変異の組合せも維持します。今後の新規取得には制約が働きます。

## 今回の実装

- 正投影の2Dトップダウン、画面幅を超える龍蛇と小さな少女
- 主戦闘帯は下端から約40%の高さ。背景スクロールで進退を表現
- 重量・位置・速度・接触・摩擦を共有する敵の押し引きと衝突
- 甲虫（軽量群体）、狼（疾走体）、猪（重量体）
- 5部位・22変異。高コストの深部変異10個と前提、重角／枝角・速筋／重頸の排他選択
- 角・顎・前胸・器官・鱗の見た目が変異に応じて変化
- 少女の足ぶらぶら・周囲の観察・歓声・押されたときの反応
- 300mごとの区間再構築と、候補を増やす永続解禁
- 乾いた荒野を基本に、進行後に骨の痕跡を配置

「集めて噛む」は反り角／重角＋大顎＋鉤触手。「引いて勢いを噛む」は鉤舌＋跳ね顎。「敵を弾く」は重角＋重頸＋弾性鱗。セットボーナスを設けず、位置・速度・重量の変化が別の器官にも作用します。速筋＋枝角＋棘鱗は軽い群れに向きます。各区間で敵の比率が変わります。

今回の範囲はコンセプトの手触りを確かめる試作です。地形の物理作用、後半の敵勢力、長編ストーリー、最終目的地は企画段階です。長距離の敵強化には上限を設けており、300mごとの再構築を繰り返して遊べます。

## 開発

Node.js 22.12以上を推奨します。

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm test`は物理相互作用、停止、購入制約、拠点・敗北復帰、セーブ検証、3系統の区間走破を確認します。`npm run build`はTypeScript検査とViteの静的ビルドです。

| ファイル | 役割 |
| --- | --- |
| `src/content.ts` | 部位・変異・敵の定義 |
| `src/simulation.ts` | 決定的な戦闘、物理、進行、購入 |
| `src/canvas.ts` | 床・龍蛇・少女・敵・変異の描画 |
| `src/main.ts` | HUD、ジェスチャー、ゲームループ |
| `src/mutation-ui.ts` | 段階別カタログ、数値、前提・排他・相性リンク |
| `src/body-layout.ts` | 身体と選択点の共通座標 |
| `src/body-physics.ts` | 描画と判定が共有する角・顎・鱗の形状、器官の先端と運動 |
| `src/battle-feedback.ts` | 舌・触手の実体、接触時の砂埃、敵HPの可視化 |
| `src/save.ts` | version 2セーブの検証と読込 |
| `tests/simulation.test.ts` | 戦闘と進行の回帰確認 |

## 公開

Cloudflare Workersの既存Git連携と`wrangler.jsonc`を維持しています。ビルドは`npm run build`、出力は`dist`、デプロイは`npx wrangler deploy`です。PRのブランチプレビューと、mainへの既存公開経路を利用します。

GitHub ActionsはPRとmainへのpushで、Node.js 22の標準runnerにより`npm ci` → `npm test` → `npm run build`を実行します。

以前の企画文書は検討履歴として残しています。今回のゲームの実装基準は冒頭の巨大生物モチーフ・身体変異の2文書です。
