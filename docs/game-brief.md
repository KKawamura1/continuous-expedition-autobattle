# 連続進軍オートバトル：企画・実装ブリーフ

この文書には、作りたい体験と実装時の判断基準をまとめています。「必須」は試作で確かめたい体験、「有力仮説」は最初に試す作り方、「未決定」は試作を見て選ぶことです。数値や技能名は具体例です。

## 作りたい体験

> 自分で組んだ戦闘機械が自律して戦う。その限界を観察し、部品を買って改造し、予想と違う働きも含めて理解しながら、前線をさらに押し上げる。

局所的な強化効果は購入前に理解できる。一方、戦場全体でどれだけ効くかは実際に動かして初めて分かる。**観察 → 仮説 → 改造 → 再開 → 理解**の循環が面白さの中心です。普段の戦闘は自動で進み、プレイヤーが考えたいときに止められます。評価するのは戦場で起きた変化です。

## 必須：試作で成立させる体験

| 項目 | 守りたいこと |
| --- | --- |
| 自律した連続戦闘 | スマートフォンの縦画面を前提に、敵が流入し、味方が自動で戦い続ける。プレイヤーの操作は観察と改造に集中する。 |
| 任意の一時停止 | プレイヤーが好きなときに止め、稼いだ資源でビルドを変え、再開できる。一時停止は戦闘の仕組みを調整する場になる。 |
| 動く前線 | 押せば距離が進み、拮抗すれば止まり、処理しきれなければ後退する。強化の手応えと限界を距離・進軍速度・戦場の様子から読める。 |
| 観察に根拠のある購入 | 何が詰まっているか、何を変えたか、その結果がどう変わったかを画面から追える。次の購入に観察から理由が生まれる。 |
| ビルドによる異なる振る舞い | 強さの数値差だけでなく、敵の集まり方、被害の受け方、押し返すタイミングなどが変わる。敵には相性差があり、複数の戦法でその圧力に対応できる。 |
| 共通ルールから生じる相互作用 | 複数の部品が同じ戦場の性質を参照し、自然に噛み合う。初見でも因果を説明できる範囲の複雑さを目指す。 |
| 遠征の継続 | 戦場と距離が一本の道としてつながり、到達した拠点が保存・再開・構成の見直しの区切りになる。離席後も安心して再開できる。 |

## 有力仮説：最初に試す作り方

まず次の作り方で、体験が成立するか試します。

### 戦場と報酬

- 敵は画面上側から現れ、パーティは下側から進む。距離に応じて敵の種類や圧力、背景が連続して変わる。
- 撃破が前進に寄与し、被害や基礎的な抵抗が押し戻す。**進軍速度 ≈ 撃破圧力 − 基礎抵抗 − 被害圧力**を仮式として、前線の挙動を試す。敵の流入は処理負荷として働く。強化直後の前進が見えるよう、敵圧の追従を調整する。
- 敵を倒して資金を得て、奥の敵ほど報酬を高くする。初期試作では敵撃破と距離による報酬の変化を試し、前線との釣り合いを見る。
- 後退中にも戦闘と購入による立て直しができる。危険域では自動で止める案がある。自発的な撤退、敗走、途中セーブの詳しい扱いは後述の未決定事項とする。

### 改造の二つの時間尺度

- **構造を決める選択**：たとえば「遠距離攻撃で敵を引き寄せる」のように、戦場に新しい因果を加える。拠点で構成を大きく組み直す。
- **遠征中の調整**：たとえば引く強さや射程を変えるように、今見えている問題へ資金を使う。

構造を決める選択と遠征中の調整は、時間尺度の異なる二つの判断として試します。一つの遠征資金で大小の部品を買い、拠点で再配分する案もあります。通貨や画面上の分け方は試作を見て決めます。

### 共有する戦場の性質

距離、位置、速度、重量、密度、接触、押し引き、貫通などは、直感的な共通ルールの候補です。物理・魔法も、戦場での振る舞いを変える手段になり得ます。たとえば「引き寄せで敵が密集し、範囲攻撃が効く」「押し出した敵が別の敵に衝突する」といった関係を試します。初期試作では、相互作用が見える少数の性質から始めます。

## exp-18からの着想

exp-18 の5人と、記憶・記録をめぐる世界観には、今回のゲームでも活かせそうな部分があります。キャラクターの性格や関係が自律戦闘に表れると、観察する楽しさも増すかもしれません。

| 人物 | 活かせそうな要素 |
| --- | --- |
| ゴウ | 大柄で調子がよく、仲間を引き受けて前へ出る。兄ユウの行方を追っている。 |
| ツグミ | 丁寧語でも容赦がない医療研究者。治療と急所を狙う攻撃の両方に長ける。 |
| ナギ | 断れず愚痴をこぼしながら仲間を庇う。ヒバナとの忘れられた関係がある。 |
| ヒバナ | 坑で見つかった記録のない子。走り回り、仲間と一緒にいることを望む。 |
| ゲンゾウ | 観測院の記録に携わってきた年長者。人の動きを読み、記録と証言の間で揺れる。 |

旧市街の地下にある異常な**坑（あな）**、外へ出ると坑内での具体的な記憶が剥がれること、記録や持ち帰った物が体験の痕跡になることも素材として魅力があります。5人の日常には笑いもあります。連続進軍の拠点、報酬、再出発と、これらの設定が結びつく形を探したいです。

加入順や役割、坑の距離、記憶剥離が起きるタイミング、先見機や遺装の使い方は、このゲームの形に合わせて考えます。exp-18 の現行設定は [人物像と関係](https://github.com/KKawamura1/garakuta-lab/blob/main/ecology/content/character-lore.mjs)、[戦闘上の役割](https://github.com/KKawamura1/garakuta-lab/blob/main/ecology/content/roster.mjs)、[世界と物語の構想](https://github.com/KKawamura1/garakuta-lab/blob/main/analysis/CAST_REBOOT_TWELVE_TOMORROWS.md) を参考にできます。

## 最初の試作で確かめること

一画面、短い一区間、一つの拠点、少数の敵と、異なる挙動が見える複数のビルドから始めます。数や距離は試作の都合で決めます。自律戦闘、一時停止中の購入、進軍・膠着・後退、拠点での保存と再構成までを一巡させます。人物や世界観も試すなら、短い反応や拠点での会話など、小さな表現から始めます。

試作では、次の問いを実プレイで確認します。

1. プレイヤーは戦場で問題を発見し、自発的に止めて改造し、すぐ結果を見たくなるか。
2. 押す・止まる・後退する理由と、購入が効いた理由を説明できるか。距離や速度に加え、敵の滞留、被害、資金の入り方など必要な手掛かりが見えるか。
3. 異なるビルドで戦場の挙動と次に買いたいものが変わるか。戦い方の違いが数値以外にも見えるか。
4. 強化後の前進が気持ちよく、劣勢でも次に試したいことが見えるか。後退中の稼ぎと前進への挑戦が釣り合うか。
5. 拠点での再構成や途中の購入が再挑戦を促すか。中断と再開は安心して使えるか。

## 未決定：実装しながら検証して選ぶこと

| 論点 | 判断の基準 |
| --- | --- |
| 技能の供給 | 固定ツリー、ショップ、ランダム候補をどこに使うか。観察から購入理由が生まれ、繰り返すときも選ぶ意味があるか。少数候補の表示と実際の選択範囲をどう設計するか。 |
| 成長・通貨・リセット | 二層の選択を別資源にするか、遠征資金に統合するか。拠点間の購入は取り消せるか、拠点で何を振り直せるか、長期の解禁をどう扱うか。 |
| 前線と敵圧 | 進軍速度、敵出現と追従、後退時の敵、表示値の平滑化をどう結ぶか。数式よりも理解可能で安定した挙動を優先する。 |
| 拠点・敗走・中断 | 拠点の間隔、保存対象、途中再開、危険域での自動停止、撤退時に失うものをどう定めるか。気軽な実験と到達の重みを両立する。 |
| 操作と情報量 | 倍速の有無、一時停止画面、購入候補の見せ方、観察用の表示をどうまとめるか。縦画面で読めて、待ち時間や操作負担を増やさないか。 |
| 世界の広がり | 地域の変化、恒久的な解禁、物語上の終点をいつ導入するか。導入の時期を見極める。 |
| exp-18 からの着想 | 5人、坑、記憶と記録、先見機、遺装などの中から、このゲームの体験に合うものを探す。 |

## 実装時の判断

技術構成や内部アーキテクチャは、上の問いに答えられる小さな実装から選びます。例示した技能や距離を埋めることより、プレイヤーが**「この改造で戦い方が変わった」**と観察できることを優先します。試して分かったことは、この文書に反映します。
