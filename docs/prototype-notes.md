# 試作の実装判断

この試作は、[企画・実装ブリーフ](game-brief.md)の「観察 → 仮説 → 改造 → 再開 → 理解」を一巡させるための実験です。技能名、式、価格、距離は固定仕様ではありません。

## 戦場

30Hzの固定刻みでワールド座標の移動と戦闘を更新します。横幅は0〜1の坑道内、縦座標は上へ進むほど減少し、1単位を40mに換算します。ゴウ・ナギは適正距離まで近づき、接敵したらその場で前線を保ちます。ヒバナは近すぎる敵から離れますが、その移動強さは従来の半分です。ツグミ・ゲンゾウは適正距離を保ち、後退移動は0.035単位/秒を上限とします。敵は最寄りのactive隊員が0.70単位以内に入ると認識し、その後は画面外でも2次元で追跡します。未認識の敵も敵速度の45%でこちらへ進みます。攻撃は0.19単位以内、ナギの庇護は敵と対象の双方から0.3以内で対象の前側にいるときに成立します。

部隊共通の後退圧は、被害/秒から実回復/秒を引いた値、近くの敵数、隊列中心より後方へ入った敵、戦闘不能者から求めます。正味損失が2HP/秒以下なら損失由来の後退圧はなく、2〜6HP/秒で上がり、6HP/秒以上で最大です。近くの敵は7体から徐々に後退圧を生み、16体で最大になります。戦闘不能者1人で目標値0.35、2人以上で0.65、後方侵入で0.55以上です。値は上昇1.5/秒、減衰0.5/秒で追従します。部隊共通の後退押しは通常移動速度から独立し、最大0.035単位/秒です。適正距離のデッドバンド、集団から離れた場合のcohesion、軽い分離も併用します。

下向きが正の座標系なので戦線は `max(最前のactive味方のy, 最後方の生存敵のy)` です。敵がいなければ最前の味方、全滅時は直前の戦線を保って崩壊停止します。距離は `(0.77 - frontline) × 40`、速度は前フレームからの戦線変位÷時間です。敵の撃破や最前の隊員の戦闘不能で戦線の担当が切り替わると、実測速度に短い段差が生じる場合があります。カメラは戦線が画面上端から60%（下端から40%）の位置に来るよう指数補間で追従します。表示範囲は1.2ワールド単位です。

前方の敵は領域ごとにまとめて生成せず、深度に応じた空間密度 `min(0.56, 0.40 + depth × 0.000134)` で存在するとみなします。各敵種の空間密度は徘徊体50%、疾走体20%、重殻体10%、群体20%です。初期の敵味方の相対移動速度に対し、密度×相対接近速度の積分が次の遭遇距離に達したとき、画面より0.2単位前方に敵を実体化します。敵種ごとの累積値は後退でも巻き戻らず、実体化した敵は画面外でも保持します。開始時は画面内の前方28.8mを生成し、深度0m付近で約11.6体が期待値です。

敵HPの基礎値は徘徊体70、疾走体45、重殻体180、群体40です。深度倍率は `1 + depth / 1200` で滑らかに増加します。敵攻撃力の既存の深度倍率は維持します。敵同士の接触候補は一様グリッドで近傍に絞ります。

生存者は毎秒0.45HPを回復、ツグミは攻撃時に追加治療します。戦闘不能は5秒後にHP1で生存者の後方へ復帰します。現在の遠征で65m以上進んだ後の初回戦闘不能は危険停止、全員戦闘不能は崩壊停止として再開を禁止し、拠点への撤退を案内します。拠点ではその場で回復し、周辺の敵を保持します。

引く・押すは敵のワールド速度に作用し、重量で動き方が変わります。敵同士の接触・衝突損傷、薙ぎ払い、鎖雷は従来と同じ局所距離を参照します。

## 拠点と保存

300mごとに中継拠点へ到達し、体力が回復して戦闘は停止します。その時点の所持金、購入履歴、総獲得額を拠点の状態として保存します。拠点では購入分を全額払い戻して自由に組み直せます。区間中の購入は撤回できません。撤退すると拠点を出てから得た資金と購入を巻き戻し、拠点で確定した構成に戻ります。

画面外へ移ると自動停止し、進行状態をブラウザのlocalStorageに保存します。戻ったときは停止状態から再開します。拠点から十分進んだあとに拠点近くまで押し戻されるか、隊員の合計HPが19%未満になると、危険域として自動停止します。

## 次に確かめたいこと

- 滞留、被害、撃破圧から次に買いたい部品が自然に決まるか。
- 鉤引きと薙ぎ払い、衝撃打と衝突損傷、鎖雷と敵の密集に、それぞれ違う手応えがあるか。
- 初期構成では届かない拠点に、複数の改造経路で到達できるか。現在は薙ぎ払いを買う経路を自動試験で確認しています。
- 300mの区間と購入価格が観察と再開を促す長さか。資金待ちや4×で飛ばしたい時間が多い場合は空間密度と報酬を見直します。
- 拠点での全再配分と区間中の購入確定が、実験しやすさと選択の重みを両立するか。

スキル供給のランダム化、研究資源、物語の進行、音、長期の敵構成は、この試作を遊んでから決めます。

## 保存形式の更新

version 5は戦線・カメラ・集団後退・種別ごとの密度積算値と遭遇閾値、敵味方のワールド座標を保存します。v1〜v3は敵味方全体を同じ量だけ平行移動し、位置関係と保存済み距離を保って移行します。v4の領域一括生成セーブは近い敵を最大16体まで残し、未遭遇の事前生成敵を破棄して新しい密度モデルへ移行します。保存キーは維持します。
